## Megaduck to game boy camera adapter, sub PCB

A Megaduck to Game Boy Camera adapter that comes in complement of [this project](https://github.com/bbbbbr/gb_to_megaduck_cart_adapter/). Just replace the upper sub board of the orginal project by this one and you're good to go with a flashable Game Boy Camera and the special build of [Photo!](https://github.com/untoxa/gb-photo).
